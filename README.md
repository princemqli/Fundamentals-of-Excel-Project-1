# Fundamentals of Excel – Project 1

## About the Project

This project is based on Microsoft Excel and demonstrates the use of different formulas and functions on Student Grade, Sales Data, and Employee Data.

## Worksheets Used

- Project Instructions
- Students Grade
- Sales Data
- Employee Data

## Excel Functions Used

### 1. IF Function

The IF function is used to check a condition and return different results depending on whether the condition is true or false.

### 2. SUM Function

The SUM function is used to calculate the total of selected numerical values.

### 3. SUMIF Function

The SUMIF function is used to calculate the total based on a single condition.

### 4. SUMIFS Function

The SUMIFS function is used to calculate the total based on multiple conditions.

### 5. COUNTIFS Function

The COUNTIFS function is used to count the number of records that satisfy multiple conditions.

### 6. AVERAGEIFS Function

The AVERAGEIFS function is used to calculate the average of values that meet specific conditions.

### 7. AND Function

The AND function checks whether all given conditions are true.

### 8. OR Function

The OR function checks whether at least one of the given conditions is true.

### 9. VLOOKUP Function

The VLOOKUP function is used to search for a value in a table and return related information from another column.

### 10. INDEX and MATCH Functions

INDEX and MATCH are used together to find specific information from a dataset based on matching conditions.

### 11. XLOOKUP Function

The XLOOKUP function searches for a value in one column and returns the corresponding value from another column.

### 12. XMATCH Function

The XMATCH function is used to find the position of a particular item in a list.

### 13. FILTER Function

The FILTER function is used to display only those records that satisfy the given conditions.

### 14. LEFT and FIND Functions

These functions are used together to extract a particular part of text, such as extracting a first name from a full name.

### 15. UPPER and LOWER Functions

The UPPER function converts text into capital letters, while the LOWER function converts text into small letters.

### 16. TEXT Function

The TEXT function is used to format dates and numbers according to the required format.

### 17. YEAR Function

The YEAR function is used to extract the year from a date.

### 18. DATEDIF Function

The DATEDIF function is used to calculate the difference between two dates.

### 19. TODAY Function

The TODAY function returns the current date.

### 20. INDIRECT Function

The INDIRECT function creates a cell or range reference from text.

### 21. OFFSET Function

The OFFSET function creates a reference by moving a specified number of rows or columns from a starting cell.

### 22. ROUND Function

The ROUND function is used to round numbers to a specified number of decimal places.

### 23. CEILING and FLOOR Functions

The CEILING function rounds a number upward to the nearest specified multiple, while the FLOOR function rounds a number downward.
